# Rasmlarni shu papkaga yuklang

**Add file → Upload files** orqali rasm yuklang. Katalog ularni o'zi ko'rsatadi.

- **Bo'lim**: har bir bo'lim uchun alohida papka oching, masalan `Ko'ylaklar/`.
- **Nomi va narxi**: fayl nomiga yozing, masalan `Qizil ko'ylak_150000.jpg`. Pastki chiziqdan (`_`) keyingi son narx bo'ladi.
- **Bir mahsulotga bir nechta rasm**: bo'lim ichida mahsulot papkasini oching, masalan `Ko'ylaklar/Qizil ko'ylak_150000/1.jpg`, `2.jpg` ...
- **Tavsif**: rasm yoniga shu nomdagi `.txt` fayl qo'ying, masalan `Qizil ko'ylak_150000.txt`.

Rasm formatlari: JPG, PNG, WEBP, GIF, AVIF.
